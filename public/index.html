Batch check

POST/check

{ "emails": ["a@mailinator.com", "b@gmail.com"] }

→ { "results": [
    { "email": "a@mailinator.com", "domain": "mailinator.com",
      "valid_tld": true, "has_mx": true, "dns_blocked": false, "disposable": true, "should_reject": true },
    { "email": "b@gmail.com", "domain": "gmail.com",
      "valid_tld": true, "has_mx": true, "dns_blocked": false, "disposable": false, "should_reject": false }
  ] }

Use "domains" instead of "emails" to batch-check bare domains.

Response fields

valid_tld — true if the TLD is a real, ICANN-recognized suffix.

disposable — true if the domain is a known throwaway provider.

has_mx — true if the domain has MX records and can receive email.

dns_blocked — true if Cloudflare family DNS appears to block an otherwise email-capable domain; omitted when there are no MX records.

should_reject — true if the address should be blocked (invalid TLD, no MX, disposable, or DNS-blocked).
